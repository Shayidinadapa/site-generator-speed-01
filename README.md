A fast, dependency-free static site generator. `solve.js` is a byte-exact reimplementation of makefun-site 1.0.0 (front matter, Markdown, templates, links, tags, pagination) that runs about 2.6x faster than the house baseline on the practice set.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
